Scan it with the Astryx app

  1. Open the Astryx app (version 14 or later).
  2. Go to Apps → Scan.
  3. Point it at this code, check the details, tap Open.

Heads-up: this code opens a bundle hosted on this site (https). Only Astryx app versions that accept hosted previews can open it (version 14 or later); earlier versions open local-network projects only and will show "Not on your local network". On a phone, tap here instead.

The bundles
